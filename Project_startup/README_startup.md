# 🚀 Исследование стартапов: выявление перспективных компаний для инвестиций

> **Кратко:** Анализ факторов успеха стартапов на основе данных Crunchbase. Выявлены 5 перспективных категорий для инвестиций, оценены риски "бесплатных" приобретений и определена связь между количеством раундов финансирования и успешностью выхода.

---

## 🎯 Бизнес-задача

Инвестиционная компания планирует выйти на рынок венчурных инвестиций с целью покупки, развития и перепродажи стартапов. 

**Необходимо:**
- Определить факторы, влияющие на успешность стартапов
- Выявить перспективные категории для инвестиций
- Оценить риски "бесплатных" приобретений
- Разработать рекомендации по инвестиционной стратегии

## 🎯 Рекомендации для инвестора

1. **Фокус на категориях:** Biotech, Cleantech, Semiconductor — сочетают высокую доходность и потенциал роста
2. **Ранние стадии:** 50% приобретений происходит до первого раунда — рассматривайте seed-инвестиции
3. **Диверсификация:** не вкладывать более 20% портфеля в одну категорию
4. **Оценка команды:** качество и образование команды — ключевой фактор успеха
5. **Анализ рисков:** даже в перспективных категориях есть риск "бесплатных" продаж
